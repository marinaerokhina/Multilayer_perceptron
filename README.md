# Seoul Bike Sharing — Multilayer Perceptron Regression

[Русская версия](README_RUS.md) · [Linear regression baseline](https://github.com/marinaerokhina/Linear_regression)

**Python · TensorFlow/Keras · scikit-learn · Neural networks · Regression**

University ML lab comparing single-layer regression networks and multilayer perceptrons for hourly bicycle rental demand. The notebook includes an introductory synthetic-data neural-network example followed by four models trained on the prepared Seoul Bike Sharing dataset.

## Data preparation

The project starts from `SeoulBikeData_prepared.csv` produced in [Lab 1](https://github.com/marinaerokhina/Linear_regression). Additional IQR-based outlier filtering removes **385 records** (8,756 → **8,371**). Input features and target are scaled with `MinMaxScaler`, followed by a **70/30 random split**.

## Models and saved results

| Model | Architecture | Features | Epochs | RMSE | R² |
| --- | --- | --- | ---: | ---: | ---: |
| M1 | 2 → 1 | Hour, temperature | 100 | 0.1924 | 0.413 |
| M2 | 2 → 64 → 32 → 1 | Hour, temperature | 100 | 0.1626 | 0.581 |
| M3 | 5 → 1 | Five weather/time features | 100 | 0.1858 | 0.453 |
| **M4** | **5 → 64 → 32 → 1** | **Five weather/time features** | **300** | **0.1441** | **0.671** |

Hidden layers use **ReLU**, the output layer is linear, and models are trained with **Adam** and **MSE** loss.

**Result:** M4 gave the best saved metrics. Note that **RMSE is calculated on the normalized target scale**, not in raw bicycle counts. Results may vary with random initialization and software versions.

## Run

Install `requirements.txt`, then open the notebook in Jupyter and execute it from the repository directory. **Training all four neural networks can take time.**

## Limitations

This is an educational comparison, not a production prediction system. **Scaling is performed before the train/test split** in the original lab, which introduces a possible information-leakage risk. A truly prospective time-series evaluation would also use a chronological split.

## Dataset attribution

[Seoul Bike Sharing Demand, UCI](https://archive.ics.uci.edu/dataset/560/seoul+bike+sharing+demand), based on V. E. Sathishkumar, [Mendeley Data V2 (2020)](https://doi.org/10.17632/zbdtzxcxvg.2). The project's input CSV is derived from an intentionally modified classroom dataset.
